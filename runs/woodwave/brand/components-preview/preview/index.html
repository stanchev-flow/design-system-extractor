WoodWave Gallery

A warm, two-tone editorial system built on a single high-contrast didone serif set uppercase at every display tier. Cream canvas hosting staggered, hard-edged photography with marginal micro-captions; deep warm-brown bands as bookends; enormous ghost watermark words behind content; zero interface chrome. Hierarchy is carried by type size, surface flips, and overlap.
